\# Лабораторийн ажил 05 — Postman болон Newman ашиглан API тестлэх



\## Оюутны мэдээлэл

\- Оюутны код: B210910878

\- Нэр: Оюунсүрэн Мөнхзолбоо



\## Зорилго

Энэхүү лабораторийн ажлын зорилго нь Registration API-г Postman болон Newman ашиглан тестлэх юм.



Дараах амжилттай болон алдаатай нөхцөлүүдийг тестэлсэн:

\- Амжилттай хичээл бүртгэл

\- Оюутан байхгүй

\- Оюутан идэвхгүй

\- Хичээл байхгүй

\- Урьдач нөхцөл дутуу

\- Хүсэлтийн шаардлагатай өгөгдөл дутуу

\- JSON формат буруу

\- Урьдач нөхцөлгүй хичээл

\- Нэг хүсэлтэд хоёр алдаа зэрэг үүсэх нөхцөл



\## Тестийн хувилбарууд



| № | Тестийн нөхцөл | Хүлээгдэж буй үр дүн |

|---|---|---|

| 1 | Амжилттай бүртгэл | 201, OK |

| 2 | Оюутан байхгүй | 200, ERROR\_NO\_STUDENT |

| 3 | Оюутан идэвхгүй | 200, ERROR\_INACTIVE\_STUDENT |

| 4 | Хичээл байхгүй | 200, ERROR\_NO\_COURSE |

| 5 | Урьдач нөхцөл дутуу | 200, ERROR\_PREREQUISITES |

| 6 | studentID дутуу | 400, ERROR\_BAD\_REQUEST |

| 7 | JSON формат буруу | 400, ERROR\_BAD\_JSON |

| 8 | Урьдач нөхцөлгүй хичээл | 201, OK |

| 9 | Оюутан болон хичээл хоёулаа байхгүй | 200, ERROR\_NO\_STUDENT |



\## Давхар алдааны туршилтын үр дүн



Оюутан болон хичээл хоёулаа байхгүй хүсэлт илгээхэд API нь:



`ERROR\_NO\_STUDENT`



гэсэн хариу буцаасан.



Энэ туршилтын үр дүнгээс API нь хичээл байгаа эсэхийг шалгахаас өмнө оюутан байгаа эсэхийг шалгаж байгааг тогтоосон.



\## Newman тестийн үр дүн



Postman collection-ийг Newman ашиглан командын мөрөөс ажиллуулж автомат тест хийсэн.



Ажиллуулсан тестийн үр дүн:



\- Iterations: 1

\- Requests: 16

\- Test scripts: 9

\- Assertions: 18

\- Failed requests: 0

\- Failed test scripts: 0

\- Failed assertions: 0

\- Үр дүн: \*\*PASS\*\*



Newman-ийн дэлгэрэнгүй үр дүнг `results/newman-report.json` файлд, товч үр дүнг `results/newman-summary.txt` файлд хадгалсан.



\## Дүгнэлт



Энэхүү лабораторийн ажлаар Registration API-ийн үндсэн болон алдаатай нөхцөлүүдийг Postman ашиглан тестэлж, Newman ашиглан автомат тестийг командын мөрөөс ажиллуулсан.



Нийт 16 хүсэлт ажиллуулж, 18 assertion шалгагдсан бөгөөд бүх тест амжилттай буюу \*\*PASS\*\* үр дүнтэй гарсан.



Мөн нэг хүсэлтэд оюутан болон хичээл хоёулаа байхгүй давхар алдааны нөхцөлийг туршихад `ERROR\_NO\_STUDENT` хариу буцаж байгааг тестээр тогтоосон.
